# Offline actual coarse-state baseline, 2026-10-03

Run `scripts/Measure-RainWaterCoarseReplay.ps1 -CampaignDirectory <directory>`
against a completed default Dry/Rain campaign that exported `RWCAP001`.
No game, GPU, deployment or production restore API is used.

The source campaign is
`occupied-exact-native-receipts-20261003-200143-2df864`, recorded from matched
installed/source commit afffcc536073e2346859f455d260eeab27c1a1a2. Dry capture
SHA256 is 746A24981300705B40EDE5BCB88D132ACE878E8CD1F83CAD48EED04C220B3F69;
Rain is 4CADC69EF54DDACF28F5E6716B58DB6DB7363717D81DFBDF3D11C30D6F2E25AB.
Each is exactly 2,105,440 bytes: an 88-byte little-endian header and two
513x513 binary32 arrays for native coarse bed and retained depth. The campaign
binds source world/token/revision, exact native stride4/spacing25, paused time,
generation/revision and exact canonical binary64 bits for pending time and
all four budgets. The script revalidates these receipts, source hashes and
both file hashes before and after replay.

The field and all four solver dependency headers must match that installed
commit's source text. Two isolated classes are generated by identifier
renaming plus one friend declaration; reversing those edits must reproduce
the exact source. The bridge calls real Configure for correctly sized storage,
then restores exact raw bed/depth, binary64 pending/budgets and integer
generation/revision. Production forcing, dry skip, cached interleaved edges,
donor limiter and source/sink operation order are unchanged.

Flows and scratch are absent from the capture. They start at Configure
defaults, and comparisons begin only after the first genuine solver Step,
which clears/recomputes flows. Subsequent every-Advance comparisons cover
bitwise bed, depth, X/Z flow, scratch arrays, pending, generation/revision and
all budgets. They exercise no-step/multi-step/pause/nonfinite duration calls
at Clang O0 and O2, with matching cross-optimisation endpoint fingerprints.
Malformed magic, dimensions, byte counts, bed/depth and pending are refused.
This is a restored actual state with held recorded endpoint binary32
liquid-rain/solar/wind forcing, **not historical flight replay**. Uncaptured
source edit journals, pointers, past flow and fine-tile histories are not
reconstructed.

Only O2 is timed after the correctness controls. Both clocks exclude Configure,
restore, first-step warmup, parsing, output hashing and comparisons. Four
ABBA rounds by default (bounded2–8) run sixteen genuine .25-second steps per
block from independently restored identical states. The receipt records raw
wall and available actual calling-thread CPU times, revisions and output
fingerprints. Internal cost instrumentation is disabled and restored afterward.
Calling-thread accounting on this Windows run is visibly quantised; it is
not presented as submillisecond precision. Wall timing can reflect concurrent
functional game captures, and no result is a game frame-rate measurement.
The finished script refuses timing while OpenPoseidon is present and checks
again after each arm; `-SkipBenchmark` keeps correctness checks available.
Each invocation writes a fresh UTC-named receipt directory.
