# Installed unedited natural fine-water protocol

`Test-RainWaterNaturalRuntime.ps1` is a source-only runtime candidate. Its
`-SelfTest` passes strict negative cases for duplicate/incomplete owner tiles,
wrong source revisions, malformed cycle events, wrong native bounds, triangle
mass and physical depth-class boundaries. The agent did not launch the game.
Installed acceptance remains pending the root's matched build and serial run.

Run under `scripts/with-game-lock.sh` with the expected deployed commit. Default
is one Noe OFF/ON pair; `-Maps noe,eden` adds original Everon, and `-SingleArm On`
or `Off` supports a bounded serial retry. Each process has a private version3
1280x720/MSAA4 profile, brightness1 and ordinary automatic exposure. Both
experimental fine flags are explicitly0 or1; inherited Reforger, weather test,
wetness fixture, snow and exposure overrides are cleared and restored safely.
Stock WRP/Noe archive hashes must match the original source census. The actual
mounted world is queried independently. Grass/UV jitter/temporal noise and wind
are disabled; cosmetic terrain puddles are disabled to inspect physical water.
Normal weather overcast/rain commands provide actual landscape liquid input;
particle rendering is off, with no density/snowflake override as a forcing
source. No water setter, terrain edit/grid change, synthetic mass, owner stamp,
forced owner selection, fixture puddle or shelter manipulation is used.

The default candidate is centred Noe tile24/23, physical origin4787.5/4587.5,
with a fixed view near4975/4675. Everon's optional candidate is tile32/35 at
6387.5/6987.5, with a fixed view near6475/7075. Their33x33 exact native vertices
are collected while paused, with unchanged height revision, baseline=false,
sea level, source/corpus hashes and installed EXE/DLL hashes. These JSON corpora
retain the original native collector contract and can be passed to the focused
production CPU source replay. They describe the actual captured terrain,
not interpolated original50m terrain masquerading as native detail.

Ordinary rain runs120 simulation seconds by default. A bounded additional60
simulation seconds allows actual natural liquid density to reach>0.25; actual
received rain volume and all water sinks remain separately checked. The ON arm
requires complete source-current owners, exact triangle volumes and one current
accepted renderer receipt matching world token, generation, height revision,
publication revision, dimensions and counts. Source events must establish the
fresh world's admission/retirement accounting, unchanged source revision,
at most two examined candidates and one admission per cycle, and at most eight
owners. Event counts do not measure native-read latency or scheduling cost.

Natural selection ranks the whole world, so tile24/23 is an audited candidate,
not a guaranteed owner. `candidateOwned` records its actual result; it never
turns a missing candidate into proof of that tile's admission. If absent, the
runner separately inspects an actual complete selected owner with greatest
held depth. The requested candidate views stay fixed in both arms. Actual owned
pool views have explicit separate names and are not falsely paired against the
candidate control. No claim that eight global owners cover all pools is made.

The selected owner gets an exact paused native vertex corpus and1024 actual
cell-centre depth/height/physical-terrain queries. Representative held fine
corners must equal the independently queried unedited native vertices; local
depth/head must match the horizontal triangle-clipped query. The report separates
actual dry, <8mm thin film, 8..50mm transition and >=50mm standing water. These
labels match the current bounded optical transition and do not delete water or
force an expected number of deep/shallow samples. Centre sampling does not
exhaust shoreline extrema between points. Weather/exposure may vary across
processes; screenshots are descriptive, not an exact lighting-isolated ablation.

Pause, camera-away/return and repeated reads must preserve clock, source,
actual weather, pending solver time, budgets, generation/revision, owner
geometry and held volume exactly. After actual rain stops,120 simulation seconds
of no-input drainage must reduce volume without new rain, edit or reset.
Optional `-RetirementSeconds` observes further ordinary drying. Full retirement
is accepted only if zero owners retain the valid paired coarse backend, current
source and increased topology generation, with an exact accepted flags3
zero-owner renderer receipt. Wet owners are never deleted to make this pass;
a bounded wait without full retirement is explicitly recorded as unobserved.
Shelter-aware CPU hydrology is not claimed: existing physical fragment support,
roof/snow/sea guards remain rendering gates requiring separate visual review.

Both streams, engine log, RPC transcript, PNG hashes, settings, private mission
and profile hashes, source corpora, held depth samples and per-view snapshots
are retained under `build/rain-water-natural`. Normal zero exit, completed
shutdown, no validation failures and unchanged installed stamp/hashes are
mandatory. Ownership is checked periodically as well as before startup. A
forced cleanup marks the campaign failed and is never accepted as normal exit.
The wrapper remains experimental source/lifecycle evidence; root must inspect
actual water optics, edges, coverage and cost before any default activation.
