# Cached-view COUNT binding, 28 September 2026

The private per-view COUNT readbacks originally described one freshly drawn request. A cached shadow or sky image can be reused after that request is gone, so treating a later raw zero as an answer for the current image would be unsafe. The opt-in implementation now retains a mapped result only with its committed publication generation and target image identity for interior sky directions 0–4, GI RSM view 5 and local shadow tile 0. It keeps the original token/model/source revision/instance epoch. The local key also carries the atlas shape, allocation generation, light key and day/night cull index. The GI key carries its own RSM texture allocation generation and exact sky view. A missing draw, failed submit, abort, refresh, changed source/key/view/epoch or late readback returns Unknown.

The existing three-slot batch supplies raw COUNT words for interior directions 1–4. Binding requires the copied-word mask and that direction's successful CPU image publication in the same request. The ordinary renderer path still allocates no COUNT staging buffers, issues no new GPU copies and makes no Fine-release decision. The integrated Rust library check, focused state/publication/headless-GPU tests, combined desktop build and paired installed WGPU startup passed at b717811f. These checks establish the integrated path compiles and starts; they do not establish cached all-view visibility or matched performance.

Follow-up `2e8feec7` extends that historical publication binding to local shadow tiles 1–23. Each tile requires its copied batch word and exact successful same-request CPU publication, atlas allocation generation and shape, tile key, day/night cull index, instance epoch and source identity. Refresh, abort, stale source and late mapping fail closed. Four focused state tests and the strict actual-GPU tile 1/tile 23 test passed in the isolated port. The full Rust library suite reported 509 passes and four failures in other ABI/shader/grass tests; their baseline status is unverified. The integrated desktop build and installed runtime check are pending while Oliver uses the installed W12d game.

A callback for the main queue proves preceding queue work only; it does not prove each cached image's pixel visibility or physical memory reclamation. The existing 36-view state machine is not yet connected to an atomic, generation-aware snapshot. A complete subset of views is not an all-36 absence certificate. The experimental GeometryPage default remains off and Fine retirement is forbidden.
