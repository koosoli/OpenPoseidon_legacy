# Optional transfer of a published warm texture before model cancellation

Source c803fa3c adds exact startup `WGR_OBJECT_STREAM_WARM_PUBLISHED_REUSE=1`. Before `DropStale` cancels a leaving model's publication, the main owner can inspect at most 32 already stored entries. A still-valid warm PAA chain with an initialized archive identity, matching inventory/model index and previously nonstale transition loses only its model publication token. Later worker Puts retain their token and are cancelled normally. The original store timestamp, source lease, chain, alpha facts, byte charge, TTL and budget remain; world Clear erases the entry. The owner must still validate the current mounted physical member and parsed header/chain before upload. A 32-entry insertion-order prefix can miss an eligible entry, so the method has no completeness or fairness guarantee. It is OFF by default; the default branch has a small cached flag check and is not claimed zero-cost.
