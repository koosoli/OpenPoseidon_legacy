# Compatibility

Original Operation Flashpoint / Arma: Cold War Assault content is the primary
gameplay target. Rendering, physics and streaming changes remain under active
development; a successful test with one unit or mission does not imply support
for every mod or savegame.

The local content browser can discover compatible terrain sources from installed
Arma, Arma 2, Arma 3, DayZ and Arma Reforger installations. Format readers and
conversion tools are included in the engine source. Imported terrain can be used
with OFP units in the native mission editor. Material interpretation, object
streaming and model/LOD compatibility are incomplete for some modern content.
An imported map is not a port of that game's simulation, missions or configs.

Vehicle compatibility uses selected local conversion paths. It does not promise
that arbitrary modern vehicles work with OFP gameplay. Swimming engine support
does not include a third-party swimming animation addon. Locally installed addons
are subject to their own license terms and are not part of this source release.

You must supply legally acquired local game content. The engine does not change
the rights granted by the original game or addon owner. Generated conversions
of proprietary maps and assets must not be uploaded with this repository.
