# Contributing

Describe the problem, the resulting behavior and how you verified it. For visual
changes, provide reproducible settings and captures made with content you may
share. Keep unrelated changes separate and preserve existing compatibility
unless correcting a demonstrated regression.

Use the build instructions in [BUILDING.md](BUILDING.md). Run checks relevant to
your change and identify runtime checks that need proprietary local content.
Test fixtures should be authored or clearly documented synthetic data.

Contribute code you have the right to distribute under the applicable project
license. Preserve copyright notices and document the exact upstream revision,
license and authors for imported code. Do not contribute proprietary game data,
SDK binaries, credentials, private logs or personal filesystem paths. Report
suspected rights or security problems privately to the repository owner before
sharing the affected material in an issue.
