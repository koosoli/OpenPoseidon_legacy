# Private release candidate

This repository is a cleaned source candidate for review. It must remain private
until its owner explicitly chooses to publish it. This is not a binary release.

The candidate preserves engine features and applicable source notices, with an
independent Git history. Development instructions, internal roadmaps, local
evidence, proprietary game archives and local SDK binaries are excluded.

Before public release:

- Resolve the outstanding earlier source-chain verification for the Malprave
  AI port described in [CREDITS.md](CREDITS.md). Its existing attribution is
  preserved; a private test upload does not settle redistribution rights.
- Complete the individual resource/fixture and screenshot rights review. The
  existing fixture policy, component licences and authored-content provenance
  remain included; absence of a scan finding is not licence clearance.
- Review the exported source build/test results and compatibility limitations.
  The development build's acceptance does not certify a separate clean export.
- For a later binary download, inventory the exact resolved dependency licences
  and runtime package contents. NVIDIA NGX/DLSS libraries are not included.

Private development history and audit receipts are maintained separately from
this repository. Follow-up releases must use this repository's independent
history rather than merge development ancestry into it.
