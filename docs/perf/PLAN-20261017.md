# Performance plan, 2026-10-17

Companion to `docs/perf/AUDIT-20261017.md` (static) and `docs/perf-audit-20261014.md`
(measured). Branch `MrDudeX-perf`.

## Ground rules

- **Zero visual regression.** Same scene, camera, time, seed → per-pixel compare; target
  bit-identical; float-ordering noise only if max channel diff ≤ 2/255 and ≥ 99.9 % identical
  pixels, plus a look at the diff heatmap. Frame sequences too (no new popping or flicker).
  No gains from less work the player can see (view/shadow distance, LOD switch points,
  texture/shadow resolution, vegetation density, default settings).
- **Zero behaviour regression.** `TickHash` (`World::RecordTickStateHash`) identical with each
  switch on and off where the change touches simulation; A1 gate list (22), A3 smoke list (13),
  CWA mission start; A2 on the laptop when A2 paths change; engine unit tests at their
  baseline (10-14 audit: 13 known failures in 5 files).
- **One change per commit, behind a switch**, following the repo's convention
  (`POSEIDON_*` for engine, `WGR_*` for the renderer; `POSEIDON_GETENV_ONCE` on hot paths),
  with a `verify` mode where the change claims exactness by construction. Before/after numbers
  in the commit message.
- **Measurement protocol:** CLAUDE.md rule 0 (`DEPLOYED-FROM.txt`, matched exe/DLL),
  `scripts/with-game-lock.sh` around every launch, own binaries in
  `<CWA>\_OpenPoseidon-Perf\bin` (working dir `Remastered`), never over another session's
  binaries. ≥3 runs per arm, median and spread. Benches: the deterministic free-fly firefight
  (`perf_combat`, `--test-world-freefly 6100 6440 172 75 -10`, `POSEIDON_LOCKSTEP_HZ=30`,
  LOD governor pinned), Durras (native Everon), a stock CWA island flythrough, one A1 mission,
  one A3 showcase, A2 C0 on the laptop.
